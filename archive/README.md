# Archive

Superseded versions, kept for history and citation. The current version lives in the [repository root](../).

- **Ouroboros v1.0** (May 1, 2026): `OUROBOROS_VISION_v1.md`, `OUROBOROS_VISION_v1.pdf`. Superseded by v2.0, which restructured the governance core into two human-sovereign tiers on a Baseline foundation.

**A note for anyone citing v1.0.** It is preserved unaltered because deleting a released version would be dishonest. It is not a statement of current positions, and several of its specifics have since been withdrawn rather than merely revised. In particular: the Appendix A inheritance notes attribute commitments to traditions I have not studied and no longer cite; the AI oversight body is described at thirteen members with an internal name that has been retired; the verification protocol is described under a name and without the prohibitions that now bound it; the Tribune tenure figures are superseded; and the document describes itself as planetary governance, which is not how the architecture is scoped. Appendix C of the current Vision logs every amendment with its reason. Quote v1.0 as history, not as position.
