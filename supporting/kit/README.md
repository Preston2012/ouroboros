# THE KIT

Usable material for the six repairs. This is what you take if one of them is worth doing where you are.

**Nothing here requires permission, attribution beyond the license, or contact with the author.** There is no organization, no membership, and nobody tracking who uses this. Take a file, change it, put your own name on the version you introduce, and throw the rest away.

**Where a fact lives.** Evidence grades and polling sources are maintained in [SOURCES_AND_SUPPORT](../SOURCES_AND_SUPPORT.md), and legal status by repair is maintained in [THE_CONVENTION_WE_NEVER_HELD](../THE_CONVENTION_WE_NEVER_HELD.md). Those two are authoritative. The files here restate what a person needs in the room, and if a restatement ever conflicts with the parent document, the parent document is right and the restatement is stale. This matters because the same fact now appears in four places and this project has already shipped one error into two documents at once.

The persuading happens elsewhere. [SIX_REPAIRS](../SIX_REPAIRS.md) is the one-page case and [THE_CONVENTION_WE_NEVER_HELD](../THE_CONVENTION_WE_NEVER_HELD.md) is the working brief behind it. This directory assumes you are already convinced and need something to hand to a clerk, a colleague, or a room.

## Why there are only three ordinances

Because only three of the six can be lawfully adopted by a local body, and drafting model text for the other three would waste the time of exactly the people this directory exists to serve.

| Repair | Where it can be done |
|---|---|
| 1. Influence and gifts | Locally in part. Full federal version needs an amendment |
| 2. Sunset | Locally, now |
| 3. Term limits | Locally for local office. Congress needs an amendment |
| 4. Cures | Federal only |
| 5. Credit reports | State, and currently contested in the courts |
| 6. Feed disclosure | Federal, and constitutionally contested |

The one-pagers carry the legal status for all six, including for the three with no model text.

## About the model ordinances

**They are drafting starting points and they have not been reviewed by counsel.** Model language carries a duty of care that prose does not, because somebody may actually introduce it. Municipal ethics, sunset authority, and the qualifications of elected officers are three of the most state-specific areas of American law, and no model text can resolve them for your jurisdiction. Have your city attorney, county counsel, or an outside attorney review any version before it is introduced.

Each ordinance opens with a short list of questions to answer before drafting. Those questions are there because each one has stopped a measure somewhere at the first hearing.

**If you are qualified and you find an error in any of this, say so in the open** by opening an issue at the repository. That is the same request the parent document makes of its readers and it applies here with more force, because an error in prose costs credibility and an error in model text costs somebody a year.

## A note on the name

This directory sits inside a project called Ouroboros. The name comes from the serpent that renews itself by consuming its own tail, which is what the parent architecture claims to do through scheduled self-audit. If the name is a liability in the room you are walking into, drop it. Nothing here depends on it, and the repairs do not need the frame to stand.
